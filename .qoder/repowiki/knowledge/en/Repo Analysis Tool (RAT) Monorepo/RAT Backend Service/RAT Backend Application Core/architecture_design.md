The `main.py` FastAPI app is the sole orchestrator: it calls `init_db()` from `db.py` to create/upgrade the SQLite schema, mounts CORS middleware, then registers the four domain routers (`repos`, `metrics`, `authors`, `commits`) from `routers/`. Cross-child wiring happens here — routers depend on shared Pydantic schemas in `schemas.py`, on the DB engine in `db.py`, and on the ingestion pipeline in `ingest.py` (which runs as a background task triggered by repo-related endpoints). The same process also serves the Vite-built frontend via static mounting under `/assets` and an SPA catch-all route, so the backend doubles as the frontend host. Configuration flows through `config.py` (including `FRONTEND_DIST`), keeping runtime paths out of router code.
