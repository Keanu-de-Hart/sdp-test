Each file under `backend/app/routers/` defines one FastAPI `APIRouter` mounted at `/api/repos` with a distinct `tags` value (`repos`, `authors`, `commits`, `metrics`), giving the OpenAPI docs per-resource grouping. Shared request/response payloads live in `backend/app/schemas.py` as Pydantic `BaseModel`s (`CloneRequest`, `MetricsFilters`, `MergeRequest`). Route handlers delegate business logic to sibling packages: `..db` (SQLite connection via context manager), `..authors`, `..metrics`, and `..ingest.start_ingest_thread`; cross-router repo existence checks are shared through `_get_repo(conn, repo_id)` imported from `.repos`. The metrics router centralizes all metric queries behind a single `POST /{repo_id}/metrics/{view}` endpoint that dispatches on `view` against `metrics.VIEWS`, serializes the filter body with `json.dumps(sort_keys=True)` into a cache key, and uses `metrics.cache_get`/`cache_put` for response caching — mutating routes call `metrics.cache_invalidate(repo_id)`. File uploads go through `tempfile.NamedTemporaryFile` + `zipfile.is_zipfile` validation before spawning an async ingest thread; synchronous DB access uses `with db.connect() as conn:` blocks throughout.
