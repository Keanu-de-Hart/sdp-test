Two sibling services with no runtime coupling beyond HTTP: `backend/app` implements FastAPI endpoints that stream-parse `git log --numstat -M50%` into SQLite (WAL), while `frontend/src` is a Vite/React SPA calling those endpoints. The root `Makefile` is the sole orchestrator — it provisions `backend/.venv`, runs `npm --prefix frontend`, and exposes unified targets (`dev`, `run`, `build`, `test`, `verify`) launching both sides together or in isolation. Cross-child data flows exclusively through the documented `/api/repos*` REST contract; there is no shared library or code between the two directories. A third-party script at `scripts/verify_metrics.py` exercises the backend end-to-end against a running server to validate metric formulas.
