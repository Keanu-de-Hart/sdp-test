The app is a single React application bootstrapped by `src/main.tsx` and composed in `src/App.tsx`, which installs `BrowserRouter`, wraps every route with `ToastProvider`, and scopes repo-specific data via `FiltersProvider(repoId)` on `/repos/:repoId/*` routes. The three children split responsibilities cleanly: `pages/` owns top-level route handlers (`ReposPage`, `DashboardPage`, `AuthorsPage`) plus their own local state; `components/` provides pure presentational pieces consumed by those pages; `lib/` holds pure helpers (formatting, time, CSV, ECharts wrappers) and `state/` holds cross-cutting React contexts (`FiltersContext`, `ToastContext`). Cross-child communication flows one-way: pages consume contexts from `state/` and compose `components/`; components call `api.ts` for backend requests and use `lib/` helpers — there is no direct component-to-page prop drilling beyond what each page composes.
