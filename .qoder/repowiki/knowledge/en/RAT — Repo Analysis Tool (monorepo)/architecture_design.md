The repo is split into two sibling services with no runtime coupling beyond HTTP: `backend/app` serves FastAPI endpoints (ingestion, authors, metrics) backed by SQLite, while `frontend/src` is a Vite/React SPA that calls those endpoints. The root `Makefile` is the only orchestrator — it provisions `backend/.venv`, runs `npm --prefix frontend`, and exposes unified targets (`dev`, `run`, `build`, `test`, `verify`) that launch both sides together or in isolation. Cross-child data flows exclusively through the documented `/api/repos*` REST contract; there is no shared library or code between the two directories. A third-party script at `scripts/verify_metrics.py` exercises the backend end-to-end against a running server to validate metric formulas.
