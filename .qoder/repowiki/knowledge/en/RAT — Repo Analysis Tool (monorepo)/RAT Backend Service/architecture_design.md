The `app/` package is the single FastAPI application entry point (`main.py`) that mounts routers from `app/routers/` (authors, commits, repos, metrics) and shares state through module-level globals: a Pydantic schema registry in `schemas.py`, an SQLite connection via `db.py`, ingestion logic in `ingest.py`, and metric computations in `metrics.py`. Repository data lives under `data/repos/<id>/` as bare Git repos plus a shared `rat.db` SQLite file. The `tests/` suite mirrors this layout by constructing a fixture repo and asserting against the same ingestion/metrics code paths used by the API.
