The module is split into two layers:
- App shell: `main.tsx` mounts the React tree via `react-dom/client` with `StrictMode`, then delegates to `App.tsx`. `App` composes global providers (`ToastProvider`, `FiltersProvider`) around a `BrowserRouter` + `Routes` layout that renders `NavBar` and three page routes (`/`, `/repos/:repoId/dashboard`, `/repos/:repoId/authors`). A helper `DashboardRoute` component reads `params.repoId`, validates it, and wraps `DashboardPage` in `FiltersProvider` so filter state is scoped per repo.
- Page components: `ReposPage` manages repository lifecycle (upload zip, clone URL, delete, polling active repos); `DashboardPage` composes summary cards, growth timeline, treemap, author panel, file metrics, and commit set table under a shared `FilterBar`; `AuthorsPage` implements manual identity merging against the backend API. All pages consume data through hooks in `../lib/hooks` (`useRepo`, `useAuthors`, `isRepoActive`) and mutations through `../api`, keeping UI logic separate from network concerns.
